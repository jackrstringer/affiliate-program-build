# Style library

**Show the PNGs. Ask which family. Restyle to this brand.**

Do not assume the user has seen CASED or eskiin. These are *armatures*, not identities to copy.

| ID | Example PNGs | Armature |
|---|---|---|
| **F** (default for new builds) | `cased-f/purchase.png` `sale-live.png` `payout.png` `pending.png` | Dark canvas. Thin type. Greeting + headline + specific sub. Accent **once** on the short link chip. Text CTA. Quiet closer + unsubscribe. Photo on most emails; pending/rejected logo-only. |
| **D** | `cased-d/sale.png` | Dark quiet receipt. Accent on earn figure + filled CTA. |
| **E** | `cased-e/sale.png` | Paper background, serif headline, almost no accent. |
| **eskiin-d** | `eskiin-d/welcome-a.png` `sale.png` `payout.png` `link.png` | Light canvas, bright pill CTA, split stats, dark band with link chip. Only if they pick it. |

## How to present

1. Render or attach the example PNGs (phone width).
2. Ask: “F (default), D, E, or the light/lime family?”
3. After they pick: restyle **wordmark, accent hex, type** from *this* brand. Keep the armature (spacing, hierarchy, chip, closer).
4. If they send extra comps, those override library details — they do not skip the pick.

Discarded (do not show): tracked uppercase kickers (`PURCHASE ALERT` with wide letter-spacing), lime-on-CASED restyles, invented “no tiers” copy.
